# Quantum Measurement Fingerprint (QMF) Specification

The QMF is the central evidence object generated by the Q-SHIELD mathematical engine. It contains heterogenous metrics derived from the actual measurements taken during quantum simulation.

## Definition

The QMF is defined as the following JSON object:

```json
{
  "bloch": {
      "rx": "<float>",
      "ry": "<float>",
      "rz": "<float>"
  },
  "fidelity": "<float>",
  "basis": {
      "X": {
          "observed_distribution": {"0": "<float>", "1": "<float>"},
          "baseline_distribution": {"0": "<float>", "1": "<float>"},
          "tv_distance": "<float>",
          "confidence_radius": "<float>",
          "significant": "<bool>"
      },
      "Y": {
          "observed_distribution": {"0": "<float>", "1": "<float>"},
          "baseline_distribution": {"0": "<float>", "1": "<float>"},
          "tv_distance": "<float>",
          "confidence_radius": "<float>",
          "significant": "<bool>"
      },
      "Z": {
          "observed_distribution": {"0": "<float>", "1": "<float>"},
          "baseline_distribution": {"0": "<float>", "1": "<float>"},
          "tv_distance": "<float>",
          "confidence_radius": "<float>",
          "significant": "<bool>"
      }
  },
  "bell": {
      "C_XX": "<float>",
      "C_ZZ": "<float>"
  },

  },
  "freshness": {

  },

  }
}
```

## Mathematical Formulations

### 1. Bloch Vector ($\vec{r}$)
For basis $B \in \{X, Y, Z\}$:
$$r_B = \hat{p}_B(0) - \hat{p}_B(1)$$
where $\hat{p}_B(0)$ and $\hat{p}_B(1)$ are the empirical probabilities derived from $N$ finite shots. The vector is $\vec{r} = (r_x, r_y, r_z)$.

### 2. Fidelity ($F$)
For pure target state $|\psi\rangle$, fidelity is calculated via state vector evaluation:
$$F(|\psi\rangle, \rho_{obs}) = \langle \psi | \rho_{obs} | \psi \rangle$$
Where $\rho_{obs}$ is the reconstructed density matrix or evaluated via Uhlmann's theorem.

### 3. Total Variation Distance ($D_{TV}$)
For probability distributions $P_{obs}$ and $P_{base}$ over binary outcomes $\{0,1\}$:
$$D_{TV} = \frac{1}{2} \sum_{i \in \{0,1\}} | \hat{p}_{obs}(i) - p_{base}(i) | = | \hat{p}_{obs}(0) - p_{base}(0) |$$

### 4. Confidence Radius ($\epsilon_H$)
Calculated via Hoeffding's inequality for bounded binary outcomes:
$$\epsilon_H = \sqrt{ \frac{\ln(2/\delta)}{2N} }$$
where $\delta = \delta_{total} / 3$ (Bonferroni correction over 3 bases). If $D_{TV} > \epsilon_H$, the deviation is marked as `"significant": true`.

### 5. Bell Correlations ($C_{XX}, C_{ZZ}$)
$$C_{XX} = E[X \otimes X]$$
$$C_{ZZ} = E[Z \otimes Z]$$
Derived from parity measurements where equal outcomes ($00, 11$) contribute $+1$ and differing outcomes ($01, 10$) contribute $-1$. 

### 6. Channel Loss ($L$)
Loss probability over the quantum channel, mapped $[0,1]$.

### 7. Freshness & Identity
Deterministic boolean validation derived from cryptographic context and metadata.
