## 1:15 - The Threat Engine (Live Demonstration)
*(Action: Navigate back to OVERVIEW, click 'RUN LIVE DEMO')*

"But what happens when an attacker intervenes? We built an automated Demo sequence that executes our backend simulator against four distinct scenarios.

1. **Legitimate Session**: The baseline noise remains within our calculated Hoeffding radius. The signature is ACCEPTED.
2. **Forgery Attack**: Eve attempts to forge the state. The $Z$-basis distribution spikes. The Total Variation (TV) distance breaks the confidence envelope. The Threat Engine deterministically flags a FORGERY.
3. **Replay Attack**: The quantum state is correct, but our context/freshness identifiers show state exhaustion. The system flags a REPLAY.
4. **Channel Manipulation**: Eve attempts an intercept-resend attack. The Bell correlation crashes below 0.5. The entanglement is broken, and the system immediately attributes this to CHANNEL MANIPULATION."
